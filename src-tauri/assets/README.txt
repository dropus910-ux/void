==============================================================
  VOID - READ ME
==============================================================

Welcome to VOID, a music player for the songs on your computer.
This folder (C:\VOID\README) is created by VOID and explains how it
works and what you should know before you use it.


--------------------------------------------------------------
1. THE VOID FOLDER
--------------------------------------------------------------
VOID keeps its files in C:\VOID

  C:\VOID\Music    Your music library. Songs you add or download land
                   here, and so do your playlists and Liked Songs.
  C:\VOID\Logs     void.log - errors and important events, so problems
                   can be found and fixed.
  C:\VOID\README   This guide, the license and the third-party notices.

Already have music somewhere else? Open the Library button (folder icon
in the top-right dock), press "Change" next to "Music folder" and pick
that folder. VOID remembers it. Playlists and Liked Songs are then kept
inside whatever music folder you picked.


--------------------------------------------------------------
2. ADDING SONGS
--------------------------------------------------------------
Press the three dots at the top right to open the dock.

  "+" button
      Import songs...            copy songs from anywhere on your PC
      New playlist...            make a playlist (it is a folder)
      Add folder as playlist...  use a folder you already have as a
                                 playlist
  "Add song" button
      Paste a link or type a song name, then press "Add song".
      The first time, VOID downloads the helper tools it needs
      (this can take a few minutes). You can show or hide the
      terminal window that does the work.

Supported files: mp3, m4a, flac, ogg, opus, wav, aac, wma.


--------------------------------------------------------------
3. PLAYLISTS AND LIKED SONGS
--------------------------------------------------------------
  - A playlist is simply a folder of songs inside your music folder.
    The folder name is the playlist name.
  - Library button: switch between All songs, Liked Songs and your
    playlists.
  - Heart button (next to shuffle and repeat): likes the song. A copy
    of the song is placed in the "Liked Songs" folder. Press the heart
    again to remove that copy (only the copy inside "Liked Songs" is
    removed - the original file stays where it is).
  - Right-click a song: Play next, Add to queue, Add to playlist, Like.


--------------------------------------------------------------
4. OTHER BUTTONS AND KEYS
--------------------------------------------------------------
  Queue button       see and edit "Up next"
  Moon button        sleep timer (15/30/45/60 min or end of the song)
  Lightning button   Smooth mode - lighter effects for slower PCs
                     (VOID turns it on by itself if things are slow)

  Left / Right   browse songs          Enter   play
  Space          play / pause          S       shuffle
  R              repeat                F       fullscreen
  N              now playing           C       card stack
  A              rain sound            M       open / close the dock
  Ctrl+K         search


--------------------------------------------------------------
5. IF SOMETHING GOES WRONG
--------------------------------------------------------------
  - Open C:\VOID\Logs\void.log - the last lines usually say why.
  - Song list is empty: check that your songs are in the music folder
    (Library button shows which one) and are a supported type.
  - VOID feels slow: press the lightning button (Smooth mode).
  - "Add song" fails: check your internet connection and try again.
  - Before sending the log to anyone, read it - it can contain file
    names and folder paths.
